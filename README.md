### Spatial Accessibility Analysis (Healthcare)

Analysis Workflow
```
Risk Layer (Cardiac Arrest Rate)
↓
Demand Layer (Land Cover + Population)
↓
Accessibility Analysis (Service Area)
↓
Weighted Overlay
↓
Location Allocation
```


Key Result

- 기존 응급실 커버리지: **1060.03 km²**
- 추가 후보지 적용 후: **1176.35 km²**
- 증가 면적: **+116.33 km²**
